# 海康相机颜色检测项目 - 核心实现说明

## 一、背景知识

### 1.1 HSV 色彩空间

HSV（Hue, Saturation, Value）是一种基于人类视觉感知的色彩空间，相比 RGB 更适合颜色识别任务。

- **H (色相/Hue)**: 0-180（OpenCV 标准），表示颜色的种类（红、黄、绿等）
- **S (饱和度/Saturation)**: 0-255，表示颜色的纯度（0=灰色，255=纯色）
- **V (亮度/Value)**: 0-255，表示颜色的明暗程度（0=黑色，255=最亮）

**为什么使用 HSV？**
- RGB 对光照变化敏感，相同颜色在不同光照下 RGB 值差异大
- HSV 中，H 通道主要反映颜色种类，受光照影响较小
- 通过调整 S 和 V 的范围，可以过滤白色背景（低 S）和黑色阴影（低 V）

### 1.2 颜色检测原理

颜色检测的核心是**阈值分割**：
1. 将图像从 BGR 转换为 HSV
2. 定义目标颜色的 HSV 范围（lower, upper）
3. 使用 `cv2.inRange()` 创建二值掩码（mask）
4. 掩码中白色区域（255）表示匹配的颜色，黑色区域（0）表示不匹配

**特殊情况：红色检测**
- 红色在 HSV 色相环中跨越 0° 和 180° 边界
- 需要两个区间：`[0, S_min, V_min] ~ [10, 255, 255]` 和 `[119, S_min, V_min] ~ [169, 255, 255]`
- 使用 `cv2.bitwise_or()` 合并两个掩码

### 1.3 形态学处理

形态学操作用于去除噪声和小斑点：
- **开运算（MORPH_OPEN）**: 先腐蚀后膨胀，去除小噪点
- **核大小**: 通常使用 5×5 的矩形核

### 1.4 轮廓检测与尺寸测量

- **轮廓提取**: `cv2.findContours()` 从二值图像中提取目标轮廓
- **最小外接矩形**: `cv2.minAreaRect()` 计算旋转矩形，用于测量长宽
- **像素到实际尺寸**: 通过标定系数 `pixels_per_mm` 转换

## 二、项目架构

### 2.1 模块结构

```
exp_1/
├── main.py          # 命令行版本（核心检测逻辑）
├── main_gui.py      # GUI 版本（三个功能页面）
├── config.yaml      # 配置文件（颜色参数、标定系数）
├── launcher.py      # 启动器（选择命令行/GUI模式）
└── common/
    └── Camera.py    # 海康相机驱动封装
```

### 2.2 核心类与方法

#### Camera 类 (`common/Camera.py`)
- `__init__()`: 自动连接第一台相机并开始取流
- `getCameraData()`: 获取一帧图像（BGR 格式的 numpy 数组）
- `CloseCamera()`: 关闭相机连接

#### ConfigManager 类 (`main.py`)
- `load_config()`: 加载 YAML 配置，自动转换 HSV 参数为 numpy 数组

#### 核心检测函数 (`main.py`)
- `run_detection_once(image, cfg)`: 执行一次颜色检测
  - 输入：原始图像、配置对象
  - 输出：保存路径、中心点坐标 (cx, cy)

## 三、核心实现流程

### 3.1 检测流程（`run_detection_once`）

```
1. 读取配置
   └─> 获取当前任务模式（yellow/red）
   └─> 获取对应的 HSV 参数

2. 图像预处理
   └─> 复制图像用于绘制（image_draw = image.copy()）
   └─> BGR → HSV 转换（cv2.cvtColor(image, cv2.COLOR_BGR2HSV)）

3. 颜色分割
   ├─> 单区间模式（如黄色）:
   │   └─> mask = cv2.inRange(hsv, lower, upper)
   └─> 双区间模式（如红色）:
       └─> mask1 = cv2.inRange(hsv, lower1, upper1)
       └─> mask2 = cv2.inRange(hsv, lower2, upper2)
       └─> mask = cv2.bitwise_or(mask1, mask2)

4. 形态学处理
   └─> kernel = np.ones((5, 5), np.uint8)
   └─> mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)

5. 轮廓检测
   └─> contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, ...)
   └─> 过滤小面积轮廓（area > 1500）
   └─> 选择最大面积的轮廓作为目标

6. 尺寸测量（如果检测到目标）
   └─> rect = cv2.minAreaRect(best_cnt)  # 最小外接矩形
   └─> 计算中心点 (cx, cy)
   └─> 计算像素长度和宽度
   └─> 转换为实际尺寸：real_len = pixel_len / pixels_per_mm

7. 结果绘制
   └─> 绘制旋转矩形框（cv2.drawContours）
   └─> 绘制中心点标记（cv2.drawMarker）
   └─> 绘制长宽标注（旋转文字）
   └─> 绘制颜色标签（YELLOW/RED）

8. 结果保存
   └─> 保存到 saved_images/{save_folder}/{mode}.jpg
```

### 3.2 GUI 架构（`main_gui.py`）

**三个功能页面：**

1. **智能识别页面（DetectionPage）**
   - 显示实时图像
   - 提供颜色检测按钮（根据 config.yaml 动态生成）
   - 显示检测结果和中心坐标

2. **参数调试页面（TuningPage）**
   - 实时 HSV 滑块调节
   - 点击图像获取像素 HSV 值
   - 预览处理结果（掩码叠加显示）
   - 保存参数到配置文件

3. **尺寸标定页面（CalibrationPage）**
   - 在图像上点击两点
   - 输入实际距离（mm）
   - 计算并保存 `pixels_per_mm` 系数

### 3.3 启动流程（`launcher.py`）

```
启动器入口
├─> 检查命令行参数
│   ├─> 如果有 "detect" 参数 → 调用 main.main_entry()（命令行模式）
│   └─> 否则 → 调用 main_gui.gui_entry()（GUI 模式）
└─> 支持打包后的 EXE 运行
```

## 四、关键技术点

### 4.1 路径处理
- 支持开发模式（Python 脚本）和打包模式（EXE）
- 使用 `Path(__file__).resolve()` 获取绝对路径
- 配置文件路径智能判断

### 4.2 图像格式转换
- 海康相机原始数据 → BGR numpy 数组
- 支持 Mono8 和 RGB8_Packed 格式
- 其他格式通过 SDK 的 `MV_CC_ConvertPixelType` 转换

### 4.3 旋转文字绘制
- `draw_rotated_text()` 函数实现任意角度文字
- 使用 `cv2.warpAffine()` 旋转文字画布
- 边界检查和掩码合成，避免文字超出图像范围

### 4.4 多线程处理
- GUI 中相机连接使用独立线程，避免阻塞 UI
- 使用 `threading.Thread(daemon=True)` 确保程序退出时线程自动结束

## 六、性能优化

1. **相机连接复用**: 初始化时连接一次，后续直接取图，避免重复连接
2. **内存缓存**: 使用 `buf_cache` 缓存转换缓冲区，避免频繁分配内存
3. **图像缩放显示**: GUI 中根据窗口大小动态缩放图像，提高显示性能

## 七、错误处理

- 相机连接失败：捕获异常并提示，不中断程序
- 配置文件缺失：检查文件存在性，给出明确错误提示
- 取图超时：设置 1000ms 超时，返回 None 并提示
- 边界检查：所有图像操作都进行边界检查，避免数组越界
